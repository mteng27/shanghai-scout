## 为上海留一点慢下来的时间

沿着苏州河，可以看到工厂如何成为艺术空间，历史建筑怎样与日常街区相连，也可以只找一段舒服的滨河步道，走走停停。这个专题把这些地点放在一起，让游客按兴趣选择一段自己的上海。

这里介绍的是上海苏州河；去苏州城旅行是另一项行程。

## 这个专题有什么

| 特色 | 可以怎样使用 |
| --- | --- |
| **十一处地点插画** | 先从视觉上认识沿河公园、建筑与文化地点。 |
| **可交互的地点选择** | 在官网点选地标，查看对应介绍与规划提示。 |
| **灵活的游览方式** | 选择短途步行、艺术与建筑半日，或串联精选地点的一天。 |
| **与城市相连的故事** | 从天安千树、M50、外白渡桥等地点，认识周围的河岸与街区。 |

插画用于挑选和认识地点，实际出行请使用实时地图。选几个感兴趣的地方慢慢逛，比一次走完十一处更适合这个专题。

## 适合谁

- 初次来上海，希望在经典景点之外增加一段街区探索的游客。
- 再次到访，对建筑、艺术或城市变化有兴趣的游客。
- 喜欢少安排几个地点，给散步和停留留出余地的人。
