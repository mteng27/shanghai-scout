# Shanghai Scout

**按自己的节奏，发现上海。**

Shanghai Scout 是一个在上海维护的独立英文旅行网站，为初次到访、短暂停留和希望深入探索的国际游客提供旅行指南、插画步行路线与实用规划工具。

**[访问官网 →](https://shanghaiscout.com/)** · [English introduction](README.md)

## 适合怎样的旅行

- **初次来上海：** 把经典景点、住宿区域和交通安排连成可执行的行程。
- **深度探索或再次来访：** 在街区、博物馆和本地体验中多停留一些时间。
- **短住或转机：** 根据实际可用时间选择路线，预留交通和返程时间。

## 网站特色

| 入口 | 可以做什么 |
| --- | --- |
| [旅行指南](https://shanghaiscout.com/guides/) | 了解抵达、交通、支付、美食与游览中的实际问题。 |
| [苏州河专题](https://shanghaiscout.com/suzhou-river/) | 用插画和沿河路线认识上海的建筑与街区。 |

## 规划工具

- [行前准备检查](https://shanghaiscout.com/tools/first-day-setup-checker/)：梳理手机、支付、地图、酒店地址与机场接驳。
- [住宿区域选择](https://shanghaiscout.com/tools/hotel-area-selector/)：结合预算、停留时间和旅行方式比较住宿区域。
- [博物馆预约检查](https://shanghaiscout.com/tools/museum-reservation-checker/)：了解不同参观计划需要提前准备的事项；实际预约通过场馆渠道完成。

网站免费使用，无需注册。三日行程是可调整的参考，游客可以按自己的时间与兴趣安排旅行。
